# Full-size thesis figures

Open index.html in your browser. It works offline; keep the image files beside it. Choose Fit width, 100% pixels, 150% or 200%. Open full size opens each original PNG separately.

Three diagrams also have SVG files. Figures 5.3 and 5.8 include separate panels, which are easier to read on thesis pages than the combined figures. See CAPTIONS_AND_PLACEMENT.md for captions and evidence limitations.
