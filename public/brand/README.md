# Archon Brand Assets

Archon's mark combines a defensive shield with a precision scan reticle. Use the primary mark by default so the orange reticle remains the recognizable product signal.

## Colors

- Ink: `#111111`
- Signal orange: `#ff5600`
- Canvas: `#f5f1ec`
- Surface: `#ffffff`
- Hairline: `#d3cec6`

## Files

- `archon-mark.svg`: primary mark for light surfaces
- `archon-mark-inverse.svg`: primary mark for dark surfaces
- `archon-mark-mono.svg`: single-color use only
- `archon-wordmark.svg`: horizontal lockup for light surfaces
- `archon-wordmark-inverse.svg`: horizontal lockup for dark surfaces
- `archon-social.svg`: editable 1200 by 630 social-preview source

## Usage

- Keep clear space around the mark equal to one quarter of its width.
- Use the standalone mark at 20px or larger in interfaces and 32px or larger in print.
- Use the wordmark when the Archon name is not already visible nearby.
- Keep the orange reticle unchanged in light and dark modes.
- Do not rotate, stretch, outline, glow, add a gradient, or place the mark on a low-contrast image.
