Insecure JWT Cookie Configuration
Triage: open / CVSS: Not recorded / CWE-319
MERN-E-Commerce-Store-main/backend/utils/createToken.js:11
Issue
The JWT cookie is set with `secure: false` in development environments. This allows the token to be

attacks.
